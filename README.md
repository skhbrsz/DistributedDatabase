# DistributedDatabase
##  Лабораторна робота. Розроблення розподіленого сервісу синхронізації даних між SQL та MongoDB з використанням Apache Kafka

### Мета роботи

Метою лабораторної роботи є набуття практичних навичок розроблення розподілених інформаційних систем, у яких взаємодіють реляційна SQL-база даних та документно-орієнтована база даних MongoDB.

У процесі виконання роботи реалізується взаємодія SQL-бази даних та MongoDB через брокер повідомлень Apache Kafka. Також передбачається ознайомлення з архітектурою Producer/Consumer, передаванням та перетворенням даних, серіалізацією і десеріалізацією повідомлень, а також реалізацією механізму узгодження даних між двома розподіленими сховищами.

### Кінцевий продукт

Результатом виконання лабораторної роботи є програмне рішення, яке складається з двох окремих сервісів та використовує:

- SQL Server — реляційну базу даних;
- Apache Kafka — брокер повідомлень;
- MongoDB — документно-орієнтовану базу даних.

### Архітектура рішення

Загальна архітектура системи:

```text
SQL Database
     |
     v
  Producer
     |
     v
 Kafka Topic
     |
     v
  Consumer
     |
     v
   MongoDB
```

**Producer** — перший сервіс, який отримує дані з SQL-бази даних, формує повідомлення та передає їх до визначеного Kafka Topic.

**Consumer** — другий сервіс, який отримує повідомлення з Kafka Topic, десеріалізує отримані дані та зберігає їх у MongoDB.

Предметна область проєкту визначається відповідно до обраної реалізації.
